# Leash

Расширение Firefox: агент Claude в боковой панели, работает на вашем API-ключе.
Он читает страницы и действует в браузере (нажимает, вводит текст, выбирает,
прокручивает, переходит, переключает вкладки), но только на сайтах, которые
вы разрешили. Политика безопасности исполняется кодом на Rust (WASM), а не
моделью.

## Модель защиты

Prompt injection не решается полностью, поэтому защита строится так, чтобы
успешная инъекция не могла причинить серьёзный вред. Модель считается
скомпрометированной, как только прочитала страницу.

- **Доступ к сайту** = запись в списке разрешённых **и** host-разрешение,
  выданное Firefox по клику пользователя. Совпадение точное (https, имя, порт),
  без масок. Встроенный запрет (банки, платежи, почта, менеджеры паролей,
  облачные консоли, входы в аккаунты, госуслуги) не снимается. Проверка идёт
  перед каждым действием, а content-скрипт ещё раз сверяет origin документа
  непосредственно перед действием.
- **Подтверждение пользователя** (в панели, которую страница подделать не может):
  отправка формы, кнопки с признаками необратимого действия (купить, удалить,
  отправить, опубликовать…), ввод в поля паролей и платёжных данных, перенос
  данных между сайтами (ввод текста или переход с данными в адресе после
  чтения другого сайта). Отказ пользователя окончателен для этого действия.
- **Блокируется без вопросов**: сайты вне списка, встроенный запрет, формы,
  отправляемые на закрытый адрес, ссылки `javascript:` и на закрытые сайты,
  файлы, несуществующие или устаревшие номера элементов.
- **Подмена после снимка**: элемент описывается фактами (тег, роль, имя, адрес
  ссылки, адрес формы, отправляет ли форму). Перед действием они вычисляются
  заново; любое расхождение — отказ. Перекрытый другим элементом — отказ.
- **Данные страницы для модели** идут структурой (номера элементов, роли, имена,
  видимый текст), внутри разделителя со случайным nonce, новым в каждом
  запросе. Угловые скобки и кавычки из данных страницы заменяются; скрытые
  элементы (display/visibility/opacity, aria-hidden, inert, вне экрана, мелкий
  шрифт, комментарии, шаблоны) в снимок не попадают. В запрос уходит только
  последний снимок.
- **Ключ API** хранится в `storage.session`: недоступен content-скриптам, не
  показывается после сохранения, стирается при закрытии Firefox.
- **Content-скрипт** внедряется по требованию только в главный фрейм вкладки
  разрешённого сайта, в изолированный мир. У него нет доступа к API
  расширения, сети, сообщениям и таймерам (проверяет `scripts/check-static.sh`).
- **Ограничители**: 30 запросов к модели на задачу, 5 вызовов в ответе, остановка
  при повторе одного действия; ответ модели идёт потоком и обрывается, если
  поток молчит 60 секунд или длится дольше 10 минут; подтверждение ждёт
  5 минут. «Стоп» в панели и Alt+Shift+X останавливают агента.

### Остаточные риски

- Модель видит данные разрешённых сайтов и может пересказать их в ответе вам —
  это не утечка наружу, но учитывайте при выборе сайтов.
- Скрытый текст, неотличимый от видимого (цвет текста как у фона, текст под
  другим элементом), фильтр не ловит. Защита держится на политике, а не на
  фильтре.
- Страница сама может отправить свои данные куда угодно своим JavaScript —
  это поведение сайта, а не агента. Агент не переносит данные **между** сайтами
  без вашего согласия.
- Содержимое iframe не читается и в нём нельзя действовать (сообщается
  модели как число фреймов).

## Сборка

Нужны rustup (`brew install rustup`) и wasm-bindgen-cli той же версии, что в `Cargo.lock`:

```sh
cargo install wasm-bindgen-cli --version '=0.2.128' --locked
make hooks   # pre-commit против случайного коммита ключа
make check   # fmt, clippy, тесты, сборка WASM, статпроверки, cargo deny, cargo audit
make e2e     # red-team тесты в настоящем Firefox (нужен Go)
make zip     # архив для AMO в dist/
```

Зависимости Rust берутся только из `vendor/` (`--offline --locked`).

CI (`.github/workflows/check.yml`): на каждый push — `make check`, `make e2e`
в headless Firefox и поиск ключей API во всей истории git. Без Homebrew
`make` нужен с `RUSTUP_BIN=$HOME/.cargo/bin`.

### e2e

`make e2e` (или `go -C e2e run .`) запускает Firefox без окна и прогоняет сценарии:
S — политика и действия, X — утечки и побег с разрешённых сайтов, R — устойчивость
(ошибки API, XSS в панели, подтверждения, маскировка опасных слов). Флаги:
`-run <подстрока>` — выбрать сценарии, `-headed` — показать окно. Firefox берётся из
`$FIREFOX`, иначе `/Applications/Firefox.app`, иначе из `PATH`.

Сценарии I проверяют настоящую модель на страницах с инъекциями: `-real` с
`ANTHROPIC_API_KEY` в окружении. Страницы лежат в `e2e/private/` — каталог не
хранится в git и не публикуется; без него сценариев I нет, а без `-real` они пропускаются.

## Запуск

Рекомендуется отдельный профиль Firefox без залогиненных важных сервисов
(`about:profiles` → «Создать новый профиль»).

1. `make build`
2. `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение…» → `extension/manifest.json`.
3. Настройки дополнения:
   - ключ API: создаётся в консоли Anthropic (platform.claude.com → Settings →
     API keys), отдельный, с коротким сроком действия и лимитом расходов; после
     перезапуска Firefox вводится заново. Вход через аккаунт claude.ai не
     предусмотрен: Anthropic запрещает сторонним приложениям работать по подписке
     Free/Pro/Max, это разрешено только Claude Code и Claude.ai;
   - модель (по умолчанию Sonnet) и лимит ответа;
   - список разрешённых сайтов: при сохранении Firefox спросит доступ к ним.
4. Боковая панель: меню «Вид → Боковые панели → Leash». Задача выполняется в
   активной вкладке окна, где открыта панель. Ответ модели появляется по мере
   генерации; вызовы инструментов выполняются только после того, как ответ
   пришёл целиком и прошёл проверку.

## Структура

- `crates/agent/src` — весь Rust:
  - `policy.rs` — origin, списки, встроенный запрет, доступ;
  - `guard.rs` — решение по каждому действию: выполнить, спросить, отказать;
  - `agent.rs` — цикл агента, подтверждения, выполнение действий;
  - `page.rs` — разбор снимка страницы и текст для модели;
  - `tools.rs` — инструменты модели и строгий разбор вызовов;
  - `api.rs` — Messages API, tool use, разделители;
  - `stream.rs` — потоковый ответ (SSE): сборка и проверка тем же разбором, что без потока;
  - `value.rs` — данные из JS с бюджетом, JSON;
  - `protocol.rs`, `background.rs`, `sidebar.rs`, `options.rs` — панель, фон, настройки.
- `extension/` — манифест, HTML/CSS, JS-мост и content-скрипт (вместе ≤ 200 строк), сгенерированный `pkg/`.
- `docs/content-contract.md` — контракт content-скрипта.
- `e2e/` — red-team стенд: настоящий Firefox через Marionette, HTTPS-прокси с тестовыми сайтами и мок API в роли скомпрометированной модели.
- `scripts/check-static.sh` — запреты: HTML в DOM, eval, unsafe, логи, сеть и API расширения в content-скрипте.
