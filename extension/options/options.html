Leash — настройки

Ключ API Anthropic

Ключ создаётся в консоли Anthropic: platform.claude.com → Settings → API keys. Вход через аккаунт claude.ai невозможен: Anthropic не разрешает сторонним расширениям работать по подписке. Заведите для Leash отдельный ключ, задайте ему короткий срок действия (консоль предлагает от 1 до 30 дней) и лимит расходов.

Ключ хранится в storage.session: он недоступен скриптам на страницах, не показывается после сохранения и стирается при закрытии Firefox — после перезапуска его нужно ввести снова.

Модель

Сайты

Агент работает только на сайтах из списка разрешённых: точное совпадение схемы, имени и порта, только https, без масок и поддоменов. Запрет сильнее разрешения. При сохранении Firefox спросит доступ к сайтам из списка: без него сайт закрыт.
