Leash — настройки

Мост к Claude

Claude Code или Claude Desktop управляют Firefox через программу leash-host. Расширение само ни с кем по сети не связывается: страницы уходят только в мост, а из него — в Claude, которым вы пользуетесь. Ключ API не нужен.

  1. Установите мост: leash-host install, затем перезапустите Firefox.
  2. Подключите его к Claude Code: claude mcp add --scope user leash -- <путь к leash-host> mcp (точную команду печатает leash-host install).
  3. Разрешите ниже сайты, на которых Claude может работать.

Опасные действия Claude подтверждаете вы в отдельном окне Leash. Пароли, данные карт, одноразовые коды и CAPTCHA вводите сами: Claude они недоступны.

Сайты

Агент работает только на сайтах из списка разрешённых: точное совпадение схемы, имени и порта, только https, без масок и поддоменов. Запрет сильнее разрешения. При сохранении Firefox спросит доступ к сайтам из списка: без него сайт закрыт.
